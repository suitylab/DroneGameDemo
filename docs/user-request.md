# 用户原始需求 (Raw User Request)

使用TypeScript + Vite + THREE.js 创建一个俯视角第三人称射击游戏：

- 随机生成迷宫，通过房间，门口，走廊来连接。
- 军事基地风格，高科技，高品质的渲染画质，有灯光效果。
- 主角是一架嵌入无人机，使用键盘控制方向，鼠标控制面朝方向，鼠标点击发射子弹。具有丰富的子弹特效，包括发射枪火，子弹光效，子弹撞击特效。
- 可以在场景拾取6种枪械。
- 设计7种机甲敌人和3🀄Boss，敌人具有AI和搜索能力，搜索到玩家后进入攻击状态。
- 玩家主角在迷宫中探索并消灭敌人。消灭所有敌人后，进入下一关。
- 总共设计10关。
- 非常酷炫的HUD显示。
- 主菜单，关卡选择菜单。
